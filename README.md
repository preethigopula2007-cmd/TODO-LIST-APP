# 📝 TODO-LIST-APP

A simple and efficient To-Do List application built using Python.

### ✨ Features
- ➕ Add new tasks
- 👀 View all tasks
- ❌ Delete tasks
- ✅ Mark tasks as done
- Simple CLI interface

### 💻 Tech Stack
- Python 3
- Core concepts: Lists, Loops, Functions, Conditional Statements

### 🚀 How to Run
1. Clone the repository
2. Run `python todo.py`
3. Follow menu options 1-5
